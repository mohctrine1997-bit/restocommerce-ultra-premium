# RestoCommerce Demo Content

Cette extension de démonstration crée dix restaurants fictifs, trente produits et des variations de sauces. Elle ne crée aucun avis, aucune note ni aucun témoignage client.

Téléversez d’abord les dix visuels `demo-*.jpg` dans la médiathèque WordPress, puis lancez **Outils → Démo RestoCommerce → Synchroniser la démonstration marketplace**. Les produits et profils déjà créés sont réutilisés afin de conserver une synchronisation idempotente.
