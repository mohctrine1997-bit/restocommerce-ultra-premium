# RestoCommerce WCFM Bridge

Ce module léger relie les vendeurs publiés par **WCFM Marketplace** à la page d’accueil du thème RestoCommerce. Chaque vendeur ayant une fiche active apparaît automatiquement comme restaurant sur la marketplace.

Pour enrichir une fiche restaurant, renseignez au minimum son nom, sa bannière et son adresse dans le profil WCFM. Le champ utilisateur `restocommerce_cuisine` permet, si nécessaire, d’afficher une cuisine précise. Pour la confirmation WhatsApp par restaurant, utilisez l’un des champs de téléphone du profil WCFM ou la méta utilisateur `restocommerce_whatsapp_number`.
