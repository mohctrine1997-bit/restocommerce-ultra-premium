# Catalogue de démonstration RestoCommerce

Cette démonstration utilise dix restaurants fictifs clairement identifiés comme contenu de test. Les tarifs sont en **dirhams marocains (MAD)**. Aucun avis, note ou témoignage client n’est créé.

Les visuels sont destinés à une démonstration de marketplace ; ils doivent être remplacés par les photos et informations des véritables restaurateurs avant lancement commercial.
